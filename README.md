# 🏝️ Caribeum - Tienda del Caribe

Tienda online moderna con Firebase integrado.

## 🚀 Deploy Rápido

```bash
# 1. Ir a la carpeta
cd caribeum-firebase

# 2. Deploy a Firebase
firebase deploy --only hosting
```

Tu tienda quedará en: `https://caribeum-6c99e.web.app`

## 📁 Estructura

```
caribeum-firebase/
├── public/
│   └── index.html          ← Tu tienda
├── firebase.json           ← Configuración Hosting
└── .firebaserc             ← Proyecto vinculado
```

## 🔧 Firebase SDKs Incluidos

- **Authentication** - Login/registro de usuarios
- **Firestore** - Base de datos en tiempo real
- **Hosting** - Deploy web estático
